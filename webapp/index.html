Postman OpenAPI
Alle Aufrufe laufen über den lokalen Proxy, damit CORS kein Problem ist. Angemeldete Endpunkte brauchen ein Token, das du oben über Anmelden mit deinem eigenen Konto holst. Die Beschreibungen sind aus Pfad und Methode abgeleitet und daher knapp.
Nur dein eigenes Konto und deine eigenen Daten. Antworten kommen direkt vom Lidl Server und sind nicht gefiltert. Manche Endpunkte verändern Daten, zum Beispiel Löschen oder Senden.

Anmelden

Login läuft über OAuth2 mit PKCE gegen accounts.lidl.com. Nach dem Login antwortet Lidl mit einer Weiterleitung auf com.lidlplus.app als Schema. Dieses Schema gehört der App, der Browser kann es nicht öffnen und meldet einen Fehler. Das ist normal. Der Code steckt in dieser Weiterleitung, du liest ihn aus dem Netzwerk Protokoll und fügst ihn unten ein.

Code mit dem Web Inspector abgreifen
1. In Safari einmalig das Entwickler Menü aktivieren unter Einstellungen, Erweitert, Funktionen für Webentwickler anzeigen.
2. Vor dem Login den Web Inspector öffnen mit Wahl Befehl I, Reiter Netzwerk, und Protokoll behalten einschalten.
3. Einloggen. In der Liste die Zeile callback suchen, Status 302.
4. Diese Zeile anklicken, bei den Antwort Kopfzeilen das Feld Location kopieren oder nur den Wert hinter code daraus.
5. Unten einfügen. Die ganze Adresse oder nur der Code funktionieren beide.
In Chrome gleich, Reiter Network, Preserve log, Zeile callback, Header Location.
